# Аудит «Замка» — 24.10.2026

Версия на момент аудита: 1.13.1 (versionCode 36).

Статусы: `[исправлено]`, `[открыто]`, `[решено не исправлять]`.

## Критично

### 1. Обновление APK без проверки подписи/хеша `[открыто]`

**Где:** `src/core/update.js` (скачивание), `src/main.js` (установка через `installApk`).

**Что:** При обновлении приложение скачивает APK с GitHub Releases и запускает системный установщик. Нет проверки криптографической подписи, SHA-256 хеша или сертификата разработчика.

**Риск:** При компрометации аккаунта GitHub, MITM или подмене ответа API может быть установлен вредоносный APK с полным доступом к хранилищу.

**Рекомендация:** Проверять хеш/подпись APK перед `installApk`, либо использовать официальный Google Play канал с подписанными релизами.

### 2. Смена мастер-пароля не обновляет биометрическое хранилище `[исправлено]`

**Где:** `src/core/store.js` (`changeMasterPassword`, строки 297–310).

**Что:** При смене мастер-пароля перешифровывается хранилище, но не вызывается `deleteMasterCredential` + `saveMasterCredential` из `src/platform/native.js`. Старый пароль остаётся в биометрии Android.

**Риск:** После смены пароля разблокировка по отпечатку попытается расшифровать хранилище старым (неверным) паролем.

**Рекомендация:** В `changeMasterPassword` добавить `deleteMasterCredential()` и `saveMasterCredential(next)` при успехе.

## Высокие

### 3. Удаление хранилища не очищает настройки, категории, профиль и GitHub-токен `[открыто]`

**Где:** `src/core/store.js` (`removeVault`, строки 157–164).

**Что:** Функция удаляет только зашифрованное хранилище (`zamok_vault_v1`). Настройки, категории, идентификатор профиля и токен GitHub остаются.

**Риск:** При создании нового хранилища старые настройки могут конфликтовать (например, чужой профиль бэкапов, несоответствие категорий).

**Рекомендация:** Расширить `removeVault` очисткой `SETTINGS_KEY`, `CATEGORIES_KEY`, токена и профиля.

### 4. Импорт бэкапа и загрузка с сервера не требуют подтверждения перезаписи `[исправлено]`

**Где:** `src/main.js` (`downloadServerBackup`, `importBackupText`).

**Что:** При скачивании копии с сервера или импорте файла текущее хранилище перезаписывается без диалога «Это сотрёт текущие данные».

**Риск:** Случайное действие приведёт к безвозвратной потере текущих паролей.

**Рекомендация:** Добавить `confirmDialog` перед `importPlain`/`persist` при импорте.

### 5. Удаление категории не перепривязывает записи `[открыто]`

**Где:** `src/ui/screens/categories.js` (`onDelete`), `src/main.js` (обработчик удаления категории), `src/ui/screens/list.js` (`categoryOf`).

**Что:** Записи со ссылкой на удалённую категорию остаются с несуществующим `category.id`. `categoryOf` возвращает последнюю категорию списка как fallback, что маскирует потерю.

**Рекомендация:** Перед удалением предлагать переместить записи в другую категорию или назначить «Общее».

### 6. Редактор карты не пересчитывает бренд при смене номера `[открыто]`

**Где:** `src/ui/screens/editor.js` (сохранение карты, строка ~269).

**Что:** `cardBrand` берётся из существующей записи или пресета, а не пересчитывается по введённому номеру.

**Рекомендация:** При сохранении типа `card` вызывать `detectCardBrand` для нового номера.

### 7. GitHub-токен привязан к фиксированному ключу, а не к профилю `[открыто]`

**Где:** `src/platform/native.js` (`SERVER_TOKEN_KEY = 'zamok_github_token'`, строки 193, 245–277).

**Что:** Токен хранится под одним ключом независимо от профиля устройства.

**Рекомендация:** Включать `profile` в ключ хранения токена.

### 8. TOTP-таймер в экране деталей не учитывает блокировку хранилища `[открыто]`

**Где:** `src/ui/screens/detail.js` (строки 461–472).

**Что:** `setInterval` обновляет TOTP-код каждую секунду, проверяя только `root.isConnected`. Состояние `vault.unlocked` не проверяется.

**Рекомендация:** Очищать таймер при блокировке хранилища (`lockVault`).

## Средние

### 9. `timingSafeEqual` раскрывает длину аргумента через ранний выход `[открыто]`

**Где:** `src/core/crypto.js` (`timingSafeEqual`, строки 82–88).

**Что:** Функция возвращает `false`, если длины строк различаются, прежде чем начать побайтовое сравнение.

**Риск:** Если используется для сравнения секретов (хешей, токенов), злоумышленник может определить длину через измерение времени ответа.

**Рекомендация:** Всегда сравнивать полную длину большего аргумента или использовать `subtle.timingSafeEqual` (Web Crypto), если доступен.

### 10. Экспорт в `.json` содержит пароли в открытом виде `[открыто]`

**Где:** `src/core/store.js` (`exportPlain`, строки 312–320).

**Что:** Обычный экспорт (не `.zmk`) сериализует всё хранилище, включая пароли, CVV, секреты TOTP, в JSON без шифрования.

**Рекомендация:** Явно помечать такие файлы как небезопасные, предлагать шифрование через `.zmk`.

### 11. `clearClipboard` не очищает историю буфера обмена Android `[открыто]`

**Где:** `src/platform/native.js` (`clearClipboard`, строки 108–114).

**Что:** Запись пустой строки не удаляет скопированный пароль из истории буфера системы на некоторых прошивках Android.

**Рекомендация:** Дополнительно перезаписывать буфер случайными данными перед очисткой, если платформа позволяет.

### 12. `shareFile` оставляет зашифрованный бэкап в кэше после шаринга `[открыто]`

**Где:** `src/platform/native.js` (`shareFile`, строки 279–303).

**Что:** Файл пишется в `Directory.Cache` и не удаляется после `Share.share`.

**Рекомендация:** Удалять временный файл после шаринга.

### 13. `readSettings` не валидирует типы значений `[открыто]`

**Где:** `src/core/store.js` (`readSettings`, строки 100–108).

**Что:** Если в настройках лежит некорректный JSON или поле неверного типа (например, `autoLockMs` — строка), расчёт таймера autobusлокировки может сломаться.

**Рекомендация:** Добавить приведение типов и значения по умолчанию для критических полей.

### 14. Отсутствие `aria-live` для тостов и управления фокусом в модальных окнах `[открыто]`

**Где:** `src/ui/components/feedback.js` (`toast`, `openModal`).

**Что:** Тосты объявляются только визуально; screen reader не прочитает уведомление. При открытии модал фокус не перехватывается.

**Рекомендация:** Добавить `role="status"`, `aria-live="polite"` для тостов, ловушку фокуса для модал.
