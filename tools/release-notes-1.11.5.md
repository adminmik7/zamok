## Замок 1.11.5

**Исправлено напоминание о новой версии.**

Приложение сохраняет сведения о последнем выпуске, чтобы не дёргать GitHub при каждом запуске: сетевой запрос выполняется не чаще раза в 5 минут, а в промежутке напоминание берётся из сохранённой копии. Сохранённая копия записывалась в одном виде, а читалась как ответ GitHub API — и всегда получалась пустой. Поэтому тост «Доступна версия» появлялся только тогда, когда сетевой запрос действительно выполнялся, и почти никогда — при обычном открытии приложения.

Теперь сохранённые сведения читаются корректно: напоминание показывается и без обращения к сети.

**Проверено на устройстве:** при запуске 1.11.3 (когда опубликована 1.11.4) без сетевого запроса, из сохранённой копии, появляется тост «Доступна версия 1.11.4», висит до нажатия и открывает загрузку обновления.

**Установка**

Скачайте `zamok-1.11.5.apk` и установите поверх предыдущей версии — хранилище, настройки и профиль сохранятся.
