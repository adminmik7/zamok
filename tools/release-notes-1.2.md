## Замок 1.2

Первая стабильная сборка с работающим обновлением из приложения.

**Что нового**

- **Обновление работает до конца.** APK скачивается с настоящим прогрессом, а по кнопке «Установить обновление» открывается системный установщик Android. В 1.1 нативный плагин установщика не успевал зарегистрироваться, поэтому установщик не открывался; в первых сборках 1.2 не хватало системного разрешения на установку пакетов — теперь оно есть.
- **Исправлен крестик закрытия окон** — вместо обычного крестика рисовался фирменный знак X (Twitter) из набора иконок.
- **Прогресс загрузки** обновления теперь идёт по-настоящему, а не сразу прыгает в конец.
- В настройках видно установленную версию, там же — кнопка «Скачать обновление» и ссылка на страницу релиза.

**Установка**

Скачайте `zamok-1.2.apk` и установите поверх 1.0 или 1.1 — данные хранилища сохранятся. Если у вас уже стояла 1.1, скачайте её заново: файл релиза 1.1 перезалит исправленной сборкой.

> Сборка подписана debug-ключом. Если у вас установлена сборка с другой подписью, сначала удалите старую версию (данные восстанавливаются из бэкапа `.zmk`).
