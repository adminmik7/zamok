## Замок 1.11.2

Напоминание об обновлении больше нельзя пропустить.

**Что нового**

- Тост «Доступна версия X» теперь **висит на экране, пока по нему не тапнут**. Раньше он исчезал через четыре секунды — если в этот момент смотреть не на телефон, новость об обновлении пропускалась.
- **Тап по тосту открывает загрузку обновления** — тот же экран, что и кнопка «Скачать обновление» в настройках: прогресс, затем «Установить обновление».
- Проверка обновлений после запуска — через **15 секунд** вместо 30.
- Тост в разделе «Обновление» настроек ведёт себя так же: не исчезает сам и открывает загрузку по тапу.

**Напоминание показывается только при реально новой версии**

Тост появляется, если найденная версия новее установленной. Проверка при запуске выполняется не чаще раза в 5 минут (чтобы не дёргать GitHub дважды подряд), а в фоне напоминание не показывается — иначе его никто не увидит. Если обновление уже установлено, напоминания не будет.

**Установка**

Скачайте `zamok-1.11.2.apk` и установите поверх 1.11.1 — хранилище и настройки сохранятся. Обновление предложится прямо в приложении.
