## Замок 1.5

Скидочную карту теперь можно заполнить не руками, а камерой: навёл на штрихкод — код в поле.

**Что нового**

- **Сканер штрихкодов** в редакторе скидочной карты: кнопка справа в поле «Штрихкод» открывает камеру, приложение само находит код (EAN-13, EAN-8, Code 128 и QR) и подставляет его в поле.
  - Декодирование целиком на устройстве (jsQR) — кадр никуда не отправляется, интернет не нужен.
  - Камера включается только на время сканирования и выключается сразу после результата.
  - При первом запуске Android спросит разрешение на камеру — его нужно выдать.
- Пока сканер открыт, хранилище не блокируется: телефон не закроет данные посреди сканирования.
- **Иконки перерисованы**: в поле штрихкода стоит настоящий залитый штрихкод, рядом — рамка сканирования (раньше обе иконки читались как «решётка» и «закорючка»).
- Тип записи «Скидочная карта» теперь помечен знаком «%» — так он узнаётся в списке типов.
- Поле штрихкода принимает и цифры, и буквы (для карт с Code 128).

**Установка**

Скачайте `zamok-1.5.apk` и установите поверх 1.0–1.4 — данные хранилища сохранятся. У кого стоит 1.4, обновление предложится прямо в приложении.

> Сборка подписана debug-ключом. Если у вас установлена сборка с другой подписью, сначала удалите старую версию (данные восстанавливаются из бэкапа `.zmk`).
