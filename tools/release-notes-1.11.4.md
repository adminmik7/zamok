## Замок 1.11.4

**Технический выпуск для проверки напоминания об обновлении.**

Код тот же, что в 1.11.3 — изменён только номер версии, чтобы на него сработало напоминание.

**Как проверить**

1. Установите 1.11.3 (или обновитесь с 1.11.2 через приложение).
2. Сверните приложение и откройте его снова.
3. Через ~15 секунд должен появиться тост «Доступна версия 1.11.4».
4. Тост висит, пока по нему не нажать: нажатие открывает загрузку обновления, затем кнопку «Установить обновление».

Если тост не появился — откройте Настройки → «Обновление»: там будет виден статус проверки («Доступна новая версия», «обновлений нет» или «Не удалось проверить обновления: …»), и по этой строке сразу понятно, на каком шаге заминка.

**Установка**

Скачайте `zamok-1.11.4.apk` и установите поверх 1.11.3 — хранилище и настройки сохранятся.
