# Zamok

Менеджер паролей для Android — функциональный аналог SafeInCloud, написанный с нуля.
Личный проект, без синхронизации и без выхода в Play Store.

## Стек

Версии зафиксированы и проверены на совместимость (октябрь 2026):

| Компонент | Версия |
|---|---|
| Gradle | 8.13 |
| Android Gradle Plugin | 8.13.2 |
| Kotlin | 2.3.21 |
| Compose BOM | 2026.04.01 |
| compileSdk / targetSdk | 36 |
| minSdk | 26 (Android 8.0) |
| JDK | 17 |

Почему не AGP 9.x: он заменил классический DSL блока `android {}`, а Compose 1.12 требует
`compileSdk 37` и AGP ≥ 9.1.1. Пока нет локального окружения для проверки сборки — держимся
стабильного, хорошо документированного набора.

## Сборка

Локально окружения нет (нет JDK, Android SDK и Android Studio), поэтому сборка идёт в CI.

1. Запушить репозиторий на GitHub.
2. Workflow `.github/workflows/android.yml` соберёт debug APK.
3. Готовый файл забирается из Artifacts последнего прогона.

Чтобы собирать локально: поставить JDK 17, затем сгенерировать обёртку Gradle:

```
gradle wrapper
./gradlew assembleDebug
```

`gradle-wrapper.jar` в репозиторий не закоммичен сознательно — его создаёт команда `gradle wrapper`.

## Правила проекта

- Криптография не пишется руками. Только платформенные API (`javax.crypto`, Android Keystore)
  и проверенные библиотеки.
- Каждая фича, связанная с безопасностью, идёт с проверкой — не «вроде работает».
- `android:allowBackup="false"` остаётся выключенным: хранилище не должно уезжать в облачный
  бэкап или при переносе на другое устройство.
