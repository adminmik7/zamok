<h1 align="center">Замок</h1>

<p align="center">Офлайн-менеджер паролей для Android</p>

**Замок** хранит пароли, банковские карты, паспорта и заметки в одном зашифрованном хранилище на телефоне. Мастер-пароль никуда не отправляется и не сохраняется — все данные шифруются на устройстве.

## Возможности

- Пароли, банковские карты, паспорта и защищённые заметки
- Скидочные карты с настоящим штрихкодом (EAN-13 / EAN-8 / Code 128) — можно отсканировать на кассе
- Сканер штрихкодов камерой: навёл на карту — код в поле
- Считывание банковской карты по NFC: номер, срок действия и имя держателя (если карта их отдаёт)
- Размытие фона, пока открыт системный запрос отпечатка
- Генератор паролей с настройкой длины и наборов символов
- Поиск по названию, логину, сайту и заметкам
- Категории, избранное и сортировка
- Свой цвет и значок для каждой записи
- Фото-вложения (например, скан документа)
- Разблокировка по отпечатку пальца или лицу
- Автоблокировка при уходе из приложения и по таймеру
- Копирование с автоматической очисткой буфера обмена
- Экспорт и импорт зашифрованного бэкапа `.zmk`
- Проверка обновлений прямо из приложения и установка новой версии в один тап
- Без аналитики и рекламы: данные не покидают устройство (единственный сетевой запрос — проверка обновлений на GitHub)

## Безопасность

- Шифрование **AES-256-GCM**, отдельный IV для каждой записи
- Ключ выводится из мастер-пароля через **PBKDF2-SHA256**, 600 000 итераций, соль 16 байт
- Ключ существует только в памяти и обнуляется при блокировке
- Мастер-пароль не хранится в открытом виде; для биометрии используется защищённое хранилище Android
- Приложение не передаёт данные в сеть

## Установка

1. Откройте [Releases](https://github.com/adminmik7/zamok/releases) и скачайте `zamok-1.8.apk`.
2. Разрешите установку из неизвестных источников, когда Android попросит.
3. Запустите приложение и создайте мастер-пароль.

Требуется **Android 7.0** или новее (minSdk 24).

> Сборка подписана debug-ключом и предназначена для ручной установки. Для Google Play нужна отдельная release-подпись.

## Резервные копии

Хранилище лежит только на устройстве, поэтому при удалении приложения данные пропадают. Делайте бэкап в Настройки → «Экспорт хранилища»: файл `.zmk` зашифрован тем же мастер-паролем и открывается через «Импорт хранилища» на любом устройстве.

## Версия

**1.8** — считывание банковской карты по NFC прямо в редакторе: приложите карту к телефону, и номер, срок действия и имя держателя (если карта их отдаёт) заполнятся сами. CVV карта не отдаёт — он вводится вручную. Добавлены официальный знак NFC, понятные сообщения для выключенного NFC и карт без поддержки EMV.

**1.6** — фон приложения размывается на время системного окна отпечатка, так что содержимое хранилища не подсматривают через плечо. Скидочная карта в списке стала такой же компактной плашкой, как банковская, и на ней теперь видны выбранные иконка и цвет. Починен сканер штрихкодов: он больше не зависает на экране с камерой и читает код даже когда тот занимает малую часть кадра.

**1.5** — сканирование штрихкода камерой прямо в редакторе скидочной карты: кнопка справа в поле «Штрихкод» открывает камеру, код подставляется в поле сам. Пока сканер открыт, хранилище не блокируется. Перерисованы иконки штрихкода и сканера, тип записи «Скидочная карта» теперь помечен знаком «%».

**1.4** — новый тип записи «Скидочная карта»: магазин и штрихкод, который рисуется прямо на экране (EAN-13, EAN-8 или Code 128 — как на самой карте) и читается сканером на кассе. Штрихкод копируется в буфер, ищется по цифрам, переносится в бэкапы.

**1.3** — обновление установлено до конца: добавлено системное разрешение на установку пакетов, поэтому кнопка «Установить обновление» открывает установщик Android, а не остаётся без реакции. При неудаче приложение предложит скачать APK со страницы релиза. Файл релиза 1.2 перезалит исправленной сборкой.

**1.2** — обновление из приложения доведено до конца: APK скачивается с нормальным прогрессом, а кнопка «Установить обновление» открывает системный установщик. Исправлен крестик закрытия окон (вместо него рисовался фирменный знак X). Файл релиза 1.1 перезалит исправленной сборкой.

**1.1** — проверка обновлений внутри приложения: версия видна в настройках, новая версия скачивается и устанавливается в один тап. Исправлены отступы на Android 15–16 и импорт бэкапов `.zmk`.

**1.0** — первый публичный выпуск.
